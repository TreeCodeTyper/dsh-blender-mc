# 机位/相机参数搜索（0.6.0）

`py/search.py` 提供两种无第三方依赖的连续参数优化，供“低清渲染 → 评分 → 再搜索”
使用；本身不渲染，`score_fn(x)` 由调用方注入。

## CMA-ES

```python
from search import cmaes
best_x, best_y, trace = cmaes(score_fn, x0, sigma=0.25,
                              bounds=[(lo, hi), ...], iters=40)
```

适合 2~8 维：相机距离、俯仰、灯强、色温、角色偏移。默认种群
`4 + 3*ln(n)`，标准协方差自适应。

## 贝叶斯优化（GP + EI）

```python
from search import bayes_opt
best_x, best_y, trace = bayes_opt(score_fn, bounds, n_init=12, iters=20)
```

先随机采样，再拟合 RBF 核 GP，用 Expected Improvement 选下一个点；
适合“每次渲染 10~60 秒”的贵评估场景。GP 的 Cholesky 分解在
20~60 个样本内足够快。

## 接入方式

1. 定义参数向量 `x`（如 `[dist, height, lens, key_w, key_temp]`）；
2. `score_fn` 调 `mc_shoot`/`mc_film` 出低清帧，再用 `py/vision_check.py`
   打分（分数取负，CMA-ES 最小化）；
3. 把返回的 `best_x` 写回 `mc_shoot`/`mc_film` 参数或 preset。

当前 `mc_shoot`/`mc_film` 还没有自动调用这两个优化器；它们先作为库和
后续 `mc_search` 的算法底座。
