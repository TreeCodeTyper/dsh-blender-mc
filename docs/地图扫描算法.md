# 地图扫描算法（0.6.0）

`py/scan.py` 从 0.6.0 起不再用“对每个草地格扫一遍 `radius×radius`”的暴力做法，
改成 2.5D 地形算法。Minecraft 地表本质是“每列一个高度”，2.5D 比通用 3D
算法更准，也不需要额外模型依赖。

## 1. 平地：积分图

把扫描区域压成矩形数组：

- `height[z,x]`：该列地表 Y；缺失列为 `NaN`
- `valid[z,x]`：该列有地表
- `stand[z,x]`：该列是可站立方块（默认草地）

二维积分图 `I` 满足任意矩形和 O(1)：

```text
sum(x0,x1,z0,z1) = I[z1+1,x1+1] - I[z0,x1+1] - I[z1+1,x0] + I[z0,x0]
```

对每个像素算 `(2r+1)²` 窗口的：

- 有效格数 `cnt`
- 可站格数 `scnt`
- 高度和 `s`、高度平方和 `s2`
- 方差 `var = s2 - s²/cnt`

只有 `cnt == (2r+1)²`、`scnt == (2r+1)²`、`var ≈ 0` 才是“整窗同高度可站”。
复杂度从 `O(F·r²)` 降到 `O(N)`。

## 2. 视线：Amanatides-Woo DDA

`openness` 不再固定 `r=3..42, da=-17..17 step3` 地采样，而是从机位向
`az±half_deg` 发射 9 条 DDA 体素射线：

```text
从 (cx,cz) 开始，比较 tMaxX / tMaxZ，选择先穿过 x 网格线还是 z 网格线，
逐格走到 dist。
```

每条射线统计：

- 通视格数 `clear`
- 总格数 `total`

`openness = Σclear / Σtotal`。范围外、缺列、`height > ground + min_height`
都算被挡；但按“格比例”而不是“整条射线全有或全无”，避免一棵树把整个
方向一票否决。

`relief` 用同一组射线，统计 `height > ground + 3` 的格数比例，作为“背景有东西”
的层次分。

## 3. 去重：Poisson disk

旧版用 `(x//2r, z//2r)` 硬网格，邻近点容易挤在一起。0.6.0 用贪心
Poisson-disk：

- 先按到扫描中心的距离排序
- 依次保留与已选点距离 ≥ `max(8, 1.5r)` 的候选
- 最多 40 个候选进入视线评分

这样返回的是“彼此散开的机位”，不是同一片广场上的 10 个点。

## 4. 排序：Pareto 非支配

构图惩罚分仍然是：

- 开阔度 0.55–0.98 最舒服
- 背景 3%–25% 最像世界

但不再只按单一加权分排序。对每个机位取三个质量：

```text
oq = 1 - |openness - 0.85| / 0.85
rq = 1 - |relief   - 0.12| / 0.12
fq = flat / (2r+1)²
```

做非支配排序，`pareto` 越小越靠前；同 rank 再按原构图分、开阔度、面积排。
这样不会因为“开阔度权重 0.6”把有背景的机位全杀掉。

## 5. 相机侧过滤

`openness` 只看主体往视线方向是否开阔；但 `mc_shoot` 的相机在主体**反方向**
约 15 格处。如果那一侧是树冠/山坡，画面里会出现贴脸的大草方块。

`_camera_side_ok` 用 `surface_map` 额外带出的 `TopMap.any`（含树冠/水）和
`TopMap.wet`（水面）做两道检查：

1. 相机所在格：`any > ground+2.5` 且不是水面 → 拒绝；
2. 相机 → 主体连线：中间 `any > max(两地表)+2` 且不是水面 → 拒绝。

水面上的相机允许存在（临水机位不能全杀掉），树冠/屋檐下的相机拒绝。

## 6. 兼容性

对外接口与返回字段保持不变：

```text
surface_map / find_open_ground / openness / relief /
best_shots / rough_shots / pick_from_save
```

`best_shots` 额外返回 `pareto / crowding / inscribed / slope / horizon`，
旧调用方可以忽略。

## 7. 复杂度

| 阶段 | 旧 | 0.6.0 |
|---|---|---|
| 平地 | O(F·r²) | O(N) |
| 视线 | O(K·R·A) 稀疏采样 | O(K·R·9) DDA |
| 去重 | O(F) 网格 | O(K²) 贪心（K≤40） |
| 排序 | O(K log K) | O(K²) 非支配（K≤480） |

`surface_map` 仍然受读方块 I/O 限制，是当前扫描的总耗时大头。

## 8. 0.6.0 追加算法

### 8.1 内接面积：Felzenszwalb 距离变换

对“可站且平坦”的二值图做二维平方距离变换：先逐行、再逐列做一维
Felzenszwalb 抛物线下包络，得到每格到最近不可站格的欧氏距离。
`inscribed = dist - 1` 作为该机位能容纳的最大内接半径，写进候选。

### 8.2 坡度：Sobel + RANSAC

- `_slope_grid` 用 `np.gradient` 算单点坡度；
- `_ransac_slope` 在窗口内随机采样三点拟合 `h = ax + bz + c`，
  以 0.35 格为内点阈值，迭代 24 次，再用全部内点最小二乘重拟合；
- 两者取最大值，超过 `max_slope` 的候选直接淘汰，避免“平地旁边贴陡坡”。

### 8.3 地平线角

每条 DDA 射线额外算“从眼高到地表的最大仰角”；9 条射线取平均后：

```text
horizon = max(0, 1 - mean_angle / 45°)
```

`horizon=1` 表示完全无遮挡，`0` 表示仰角 ≥45°。它和 `openness`
（通视格比例）互补：前者看“天际线”，后者看“脚下到远处有没有断”。

### 8.4 去重：NMS

Poisson-disk 先撒候选；评分排序后再做一次显式 NMS，按
`max(8, 1.5r)` 抑制同片广场，保证 top-N 不是同一个位置换方位角。

### 8.5 排序：NSGA-II

用快速非支配排序 + 拥挤距离替换原来的简单 Pareto rank：

```text
目标：oq = 1-|openness-0.85|/0.85
      rq = 1-|relief-0.12|/0.12
      iq = min(1, inscribed/r)
      hq = horizon
```

先按前沿 rank，再按拥挤距离、构图分排序；`best_shots` 输出
`pareto` 与 `crowding`。
