## 二、修复方案（按批次，全部先进 git 仓库，再同步生产）

### P0-1 速度包（约半天）
- `build_cover.py`：`taa_render_samples` 192→48，`volumetric_samples` 96→32，暴露 `--samples` / `--vol-samples`。
- `pipeline.py`：两段式——先 960×540 / 16 采样定机位，过 85 分再 1920×1080 / 64 出图；`auto_adjust` 封顶 2 轮，且第 2 轮只在有可修问题时才跑。
- 复用同一 Blender 会话（去掉每轮 `--factory-startup`）。
- 预期：3 分钟 → 30–40 秒（首次）。

### P0-2 干净包（约 1–2 天）
- `build_cover.py` / 新 `py/blender/backdrop.py`：`backdrop=world|clean|studio` 三档。
  - `clean`：删掉 `世界` 远景（保留角色脚下 R 格），用地图自带 `grass_block_top.png` 平铺草地（已实测跑通，40s 出干净图）。
- `export_obj.py`：`--ymin` 收薄到地表 −2；新增 `--only-natural` 方块白名单（剔木石建筑）；半径默认 44→28。
- `auto_adjust` 接入「无轮廓光」→ 加 rim light；「天空太平」→ 换 AgX + 天空强度。

### P0-3 档案包（约半天）
- 新增 `py/runs.py`：每次 `shoot` / `anim` / `film` 结束写 `~/.dsh/blender-mc/runs/<ts>_<task>.json`。
- 必填字段：`id / goal / inputs / params / artifacts / verdict / score / next_action / ts`。
- `cli.py` 加 `runs list|show`，并支持 `--replay <id>`（用同一档案重跑）。

### P1-1 场景变换（约 2 天）
- `film.py`：`shots[i]` 支持 `blend` / `map` / `hour` / `fog` 覆盖；新增 `transition{type,dur}`（xfade / dip / cut）。
- 断言：两镜之间确实换了工程或环境，切点有混合帧。

### P1-2 动作原子（约 1–2 天）
- `anim_kit.py` 的 `MOTIONS` 增 6–8 个：`dash / roll / cast / block / taunt / fall / land / idle_shift`，每个 40–80 行。
- 片段化 `enter / loop / exit`，供 `film.py` 按镜头自由拼。

### P1-3 运镜 DSL（约 1 天）
- `build_camera` 增加 `moves` 解释器（约 120 行）：
  ```json
  "moves": [
    {"range": [1, 60], "type": "push_in", "from": {"dist": 9, "lens": 38}, "to": {"dist": 5, "lens": 55}, "ease": "in_out"},
    {"range": [61, 140], "type": "orbit", "deg": 90},
    {"range": [141, 240], "type": "crane_up", "dz": 2.0},
    {"range": [1, 240], "type": "handheld", "amp": 0.05}
  ]
  ```
- 顺手改 `run` / `walk` / `ride` 的 JSON：4° → 30–60° 环绕或 1.6× 推近。
- `mc_anim` 支持多镜（复用 `film.py` 的 shots + `transition`）。

### P2 收尾
- `docs/脚本地图.md`：13 个 `mc_*` 工具 → 入口脚本 → 零件脚本，一张表。
- 雷劫扩展与 `jiedan/leijie` 收回仓库；删 8 个 `*.bak_20261107`。

## 三、验收与打分机制

### 3.1 统一口径
- 满分 5 分制，**加权总分 ≥ 4.0** 且 **没有任何单项 < 3** 才允许同步生产。
- 自动指标由脚本算（进 `runs/*.json`），主观指标由人盲评（A/B 两次渲染随机顺序，不知道哪次是新版）。
- 每次改动必须跑完第五节的 5 条回归任务。

### 3.2 打分卡

| 项目 | 权重 | 测量方法 | 5 分 | 3 分 | 1 分 |
|---|---|---|---|---|---|
| 速度 | 20% | `shoot.log` 首帧到最后一帧的 wall time（1080p，含重跑） | ≤40s | ≤90s | ≥150s |
| 干净度 | 20% | 背景区（主体包围盒外）Sobel 梯度均值 + LSD 长直线条数 | 直线 ≤1、梯度 ≤基线 | 直线 3、梯度 1.5× | 直线 ≥6 |
| 运镜 | 15% | 从关键帧算：方位角总变化 A、距离变化率 D、焦距变化 F | A≥40° 或 D≥50% 或 F≥15mm，且平滑无跳变 | 命中其一但幅度不足 | 三者都 <10% |
| 切镜 | 10% | 成片中硬切/过渡点数量 C | C≥2（3 镜 demo） | C=1 | C=0 |
| 动作表现 | 15% | 原子数 n + 是否有 enter/loop/exit + 衔接跳动（相邻帧根骨骼位移） | n≥8、三段齐全、跳动 <0.05 格 | n≥5 | n=3 |
| 场景变换 | 10% | 4 项断言：blend / map / hour / fog 覆盖各 1 分 | 4/4 且切点有混合帧 | 2/4 | 0/4 |
| 档案 | 5% | `runs/*.json` schema 9 字段齐全 + `--replay` 复现（SSIM≥0.99） | 全齐且可复现 | 缺 1–2 字段 | 无档案 |
| 代码健康 | 5% | `docs/脚本地图.md` 覆盖 13/13 工具；生产树与仓库 diff=0；无 .bak | 全达标 | 覆盖率 ≥10/13 | <8/13 |

### 3.3 指标计算要点（给实现者的口径，避免各行其是）
- **速度**：在 `pipeline.py` 里打点（`t_export / t_build / t_render / t_check`），写进档案；只认 `t_total`。
- **干净度基线**：用 `h_texplane_full.png`（已确认干净）当参照，取同区域梯度均值 `G0`；新渲染 `G` 满足 `G ≤ 1.25·G0` 且直线 ≤2 即算过。
- **运镜**：从 `CAM` 的 fcurve 采样每 4 帧，算球坐标下的 `Δ方位角 / Δlog(距离) / Δ焦距`，平滑度用二阶差分（jerk）超过 `3×均值` 的帧数占比 <5%。
- **动作衔接**：读每帧根骨骼世界坐标，`max|Δp| / 帧` < 0.05 格；跨片段拼接时检查首尾姿态夹角 <15°。
- **档案复现**：同档案跑两次，`SSIM ≥ 0.99`（EEVEE 有噪声，别用哈希）。

### 3.4 回归任务集（固定 5 条，全部跑完才算一次验收）
1. 修仙封面（自定义布景 + 干净背景）
2. Cinematic Interactions 模组封面（默认 `mc_shoot` 路径）
3. `yujian` 10 秒（现有最好的运镜基线）
4. `killaura` 10 秒（旧预设，验回归不倒退）
5. 3 镜 demo（换 blend + xfade，验 P1-1）

### 3.5 验收流程
```
改代码 → 跑 5 条回归 → 自动指标落 runs/*.json
      → 生成 docs/scoreboard.md（各包分数 + 差值）
      → 人盲评 A/B（主观分）
      → Gate：加权 ≥4.0 且无单项 <3
          通过 → 同步生产树 → 记 CHANGELOG
          不通过 → 回滚，把失败项写进 runs/*.json 的 next_action
```
