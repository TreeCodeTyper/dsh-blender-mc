# 特效模块 fx_kit

`py/blender/fx_kit.py` 是一个**独立**的 Blender 特效模块，不依赖 `anim_kit.py` / `pipeline.py`，
只 `import bpy / math / mathutils / random`（标准库 `os`、`time` 仅自测入口使用）。

一句话：配方里写一个特效名 + 一个参数字典，模块自己建几何、建材质、打关键帧，返回对象列表。

```python
from fx_kit import FX_REGISTRY

ctx = {
    'arm':   arm_ob,                      # 角色骨架对象（可 None）
    'total': 240,                          # 整段镜头总帧数
    'fps':   24,
    'base':  Vector((0, 0, 0)),            # 角色脚底位置（世界坐标）
    'FV':    Vector((0, -1, 0)),           # 角色前向（水平单位向量）
    'UP':    Vector((0, 0, 1)),            # 上方向
}
made = FX_REGISTRY['embers'](scene, ctx, {'n': 90, 'strength': 3.0})
```

7 个特效名：`wind` / `glow_eyes` / `embers` / `teleport` / `spawn_in` / `splash` / `fog_gate`。

---

## 1. 契约

| 项 | 说明 |
| --- | --- |
| 签名 | `fx_xxx(scene, ctx, spec=None)`，7 个函数完全一致 |
| `ctx` | 上表 6 个键；缺失的键用 `.get()` 兜底（`total`→24，`fps`→24，`base`→原点，`FV`→`(0,-1,0)`，`UP`→`(0,0,1)`，`arm`→`None`） |
| `spec` | 该特效的参数字典；`None` 或 `{}` 全部走默认值 |
| 返回值 | 新建对象列表（含灯光对象）；`cleanup_fx()` 能一次清掉 |
| 命名 | 所有对象/材质/灯 `fx_<效果名>_<用途><序号>`，例如 `fx_embers_e017`、`fx_teleport_bar03` |
| 时间 | 所有“时刻”类参数都是**占 `total` 的比例**（0~1），与帧率无关；`spec` 里给绝对值的地方会注明单位 |

配套工具：

```python
import fx_kit
fx_kit.FX_REGISTRY          # {'wind': fx_wind, ...}
fx_kit.FX_DEFAULTS          # 每个特效的“配方级”默认值（下面各表已同步）
fx_kit.cleanup_fx()         # 删除全部 fx_ 对象（连同没人用的网格/材质），返回个数
fx_kit.cleanup_fx(hide=True)  # 只隐藏不删（hide_render + hide_viewport）
```

`FX_DEFAULTS` 与各函数 docstring 里的默认值**保持一致**，方便“先复制再改一两个键”。

## 2. 通用调参常识（踩过的坑）

1. **AgX 会把高亮糊白**。Emission Strength 超过 ~4 基本就失去颜色（火星变白点、眼睛变白块）。
   想要“有颜色的光”，把 strength 压到 2~3，靠 Base Color 压暗 + 合成器泛光出效果。
2. **自发光物体的 Base Color 要给暗色**。`emis_mat(..., base=(0.02,0.05,0.06))`；
   默认 `base=col` 会把亮底色交给环境光，AgX 下一律变奶白。
3. **半透明**：`emis_mat(..., alpha=0.1)` 内部同时设 `blend_method='BLEND'` 与
   `surface_render_method='BLENDED'`。alpha 有效，但**自发光太强会像实心板**——
   雾面/能量柱壳的 strength 保持在 0.5~1.0。
4. **泛光（Bloom）不归这个模块管**：模块只建自发光材质，画面泛光由渲染端的合成器
   `CompositorNodeGlare`（Fog Glow）给出。自测里会临时接一个，正式工程里请沿用
   `anim_kit.setup_render()` 的设置。
5. **Blender 5.2 的 Action 没有 `.fcurves`**：模块内部统一用 `_fcurves(action)`
   走 `layers → strips → channelbags`；如果你自己写关键帧后要改插值，也用它。
6. 对象很多的特效（`embers` 一颗一材质）会产生大量材质，`cleanup_fx()` 会一并回收。

## 3. wind —— 风（T10）

一圈细长薄片贴地扫过，沿角色前向飘走。

| 键 | 默认 | 单位 | 说明 / 调参建议 |
| --- | --- | --- | --- |
| `n` | 30 | 个 | 薄片数量。少于 15 会显得空；30~40 最像“一阵风” |
| `radius` | `[1.0, 2.6]` | 格 | 出生半径范围。包住角色即可，太大就散 |
| `z` | `[0.05, 0.45]` | 格 | 出生高度。都是贴地一层，抬太高会像雨 |
| `length` | `[0.8, 1.6]` | 格 | 薄片长度（即风线长短） |
| `life` | `[12, 22]` | 帧 | 单片存活时长 |
| `travel` | 6.5 | 格 | 沿风向飘的总距离；人物走动时给 8~10 |
| `rise` | 0.35 | 格 | 沿途上扬高度，避免纯水平“贴地线” |
| `strength` | 0.85 | — | 自发光。1.2 以上开始过曝发白，0.6 更柔和 |
| `color` | `[0.80, 0.88, 1.0]` | RGB | 冷白色，偏蓝一点更像风 |

时间轴：每片错开 `0~0.45*total` 出生，`f0` 出现、`f0+2` 长到 1、`f0+life` 缩到 0，位移线性。

## 4. glow_eyes —— 眼睛发光（T13）

两个自发光小方块 + 一个点光源，按呼吸节奏一起明暗。

| 键 | 默认 | 单位 | 说明 / 调参建议 |
| --- | --- | --- | --- |
| `color` | `cyan` | 名字/RGB | 可用 `cyan` `ice` `amber` `fire` `white` `gold` `violet` `purple` `green` `water` |
| `strength` | 2.6 | — | 眼睛自发光峰值。3.5 以上变白块，2.0~3.0 保住颜色 |
| `min_ratio` | 0.55 | 比例 | 呼吸最低亮度（0.5 = 明暗差一倍）；0.8 更含蓄 |
| `light` | 30.0 | W | 点光源功率，负责“脸上的光池” |
| `light_radius` | 0.12 | 格 | 点光源软硬 |
| `pulses` | 3 | 次 | 整段里呼吸几个周期 |
| `size` | `[0.085, 0.030, 0.075]` | 格 | 眼块 `[宽, 厚, 高]`；MC 皮肤眼白一般 0.08~0.11 宽 |
| `push` | 0.020 | 格 | 有骨骼时沿前向再外推，防止眼块埋进脸里 |
| `spread` | 0.105 | 格 | 无骨骼时两眼间距的一半 |
| `height` / `depth` | 1.60 / 0.20 | 格 | 无骨骼时的兜底取位（相对 `base`） |
| `at` | `None` | — | 直接给 `[[x,y,z],[x,y,z]]`（相对 `base`），优先级最高 |

取位优先级：`spec['at']` → 骨架里名字含 `eye` 的骨骼（`eye.L` / `eye.R` / `eye_l` 都认，
按 x 排左右）→ 身体比例兜底。自测日志会打印实际走的是哪一支。

呼吸实现：`Emission Strength` 与灯 `energy` 同步按 `cos` 采样，`pulses+1` 个关键帧。

## 5. embers —— 余烬 / 火星（T24）

几十个自发光小方块从地面向上飘，随机相位、随机暖色、到尾端淡出。

| 键 | 默认 | 单位 | 说明 / 调参建议 |
| --- | --- | --- | --- |
| `n` | 80 | 颗 | 数量。70~120 都能看；一颗一材质，120 以上材质会有点多 |
| `color` | `amber` | RGB | 主色（橙红） |
| `color_hot` | `[1.0, 0.58, 0.10]` | RGB | 亮芯色，按随机权重插值（越亮越黄） |
| `radius` | `[0.18, 0.95]` | 格 | 出生半径；收到 0.9 以内才“围着人转” |
| `z` | `[0.02, 0.25]` | 格 | 出生高度 |
| `size` | `[0.016, 0.036]` | 格 | 单颗边长。**超过 0.05 就像飘纸片** |
| `rise` | `[0.8, 2.0]` | 格 | 上升高度 |
| `life` | `[0.5, 0.9] × total` | 帧 | 单颗寿命 |
| `strength` | 3.0 | — | 峰值自发光。4.5 以上 AgX 就糊成白点 |
| `sway` | `[0.04, 0.14]` | 格 | 左右摆动幅度 |
| `drift_fwd` | 0.15 | 格 | 全程随前向漂移距离 |

实现细节：每 2 帧采样一次位置（线性插值），每颗一颗独立材质以便**各自淡出**
（`Emission Strength` 0 → peak → 0.75·peak → 0）。

## 6. teleport —— 传送（T32）

竖直能量柱 + 环形冲击波。分三层：很淡的雾壳圆柱、细亮芯柱、一圈竖直能量条；
到 `collapse` 时刻整体压扁并沉到地面，紧接两圈 torus 冲击波向外扩散。

| 键 | 默认 | 单位 | 说明 / 调参建议 |
| --- | --- | --- | --- |
| `height` | 2.8 | 格 | 柱高。要比角色高一点（角色约 1.9 格，用 2.6~3.2） |
| `radius` | 0.30 | 格 | 能量条分布半径；**大于 0.4 就变成“桶”把角色挡住** |
| `bars` | 10 | 根 | 竖直能量条数量；0 = 只要芯柱和雾壳 |
| `barsize` | 0.035 | 格 | 能量条截面 |
| `color` | `ice` | — | 主色 |
| `core_color` | `[0.75,0.97,1.0]` | RGB | 芯柱颜色（近白） |
| `alpha` | 0.10 | — | 雾壳不透明度。**别超过 0.2**，否则角色被吞掉 |
| `core_alpha` | 0.90 | — | 芯柱不透明度 |
| `in` | 0.08 | ×total | 出现的时刻 |
| `collapse` | 0.50 | ×total | 收缩时刻（自测渲第 12 帧就是取这个点） |
| `ring_major` | 0.62 | 格 | 冲击波起始半径 |
| `ring_grow` | 3.4 | 倍 | 冲击波最终半径倍率 |
| `flash` | 700 | W | 中心闪光功率 |

时间轴：`in` 出现 → 保持到 `collapse-1` → `collapse+2` 压扁并落到 `base.z+0.03` →
两圈环分别在 `collapse+0.5` / `collapse+2` 起爆，9 帧扩到 `ring_grow` 后淡出。
芯柱与雾壳的 `Emission Strength` 在收缩瞬间冲高（3.5→4.5→10），出“爆一下”的感觉。

## 7. spawn_in —— 物品/方块出现（T17）

目标物体从 `scale 0` 弹到 1，带 overshoot 与白闪。

| 键 | 默认 | 单位 | 说明 / 调参建议 |
| --- | --- | --- | --- |
| `object` | `None` | 名字 | 目标物体名；不给就用 `target`；都没有就造个占位方块 |
| `dist` | 1.35 | 格 | 占位方块离角色的前向距离 |
| `size` | 0.55 | 格 | 占位方块边长（一格方块用 1.0） |
| `color` | `gold` | — | 占位方块颜色 |
| `glow` | 1.4 | — | 占位方块自发光（仅占位方块用） |
| `pop` | 0.32 | ×total | 弹出时刻 |
| `overshoot` | 1.15 | 倍 | 过冲倍率（1.1~1.25） |
| `bounce` | 0.96 | 倍 | 回弹倍率（0.9~0.98） |
| `flash` | 260 | W | 闪光功率 |
| `with_flash` | `True` | — | 是否加白闪方块 + 闪光灯 |

关键帧：`pop-3 → 0.001`，`pop+2 → overshoot`，`pop+5 → bounce`，`pop+8 → 1.0`，
插值 `BEZIER`（S 曲线手感）。白闪方块 `pop-2 → 0.2` 瞬间冲到 `1.25` 再缩没。

> 给 `object` 时模块**只改 scale**（外加一个闪光灯和白闪块）；不碰目标的位置/旋转，
> 因此可以和物品本身的动画叠加。

## 8. splash —— 水花（T34）

几个方块从落点向外抛物飞散，地面留一圈涟漪环。

| 键 | 默认 | 单位 | 说明 / 调参建议 |
| --- | --- | --- | --- |
| `n` | 14 | 块 | 水花数量；10~24 |
| `color` | `water` | — | 水色 |
| `strength` | 1.6 | — | 自发光（水花偏亮好看，别超过 3） |
| `size` | `[0.09, 0.16]` | 格 | 单块边长 |
| `vz` | `[3.2, 5.2]` | 格/秒 | 初始竖直速度 |
| `vh` | `[1.5, 3.4]` | 格/秒 | 初始水平速度 |
| `gravity` | 22.0 | 格/秒² | 重力；MC 手感偏大，18~26 |
| `start` | 0.18 | ×total | 起跳时刻（落水那一刻） |
| `ring` | `True` | — | 是否画地面涟漪环 |
| `ring_radius` | `[0.6, 2.2]` | 格 | 涟漪最终半径（只用第二项） |
| `origin` | `None` | 格 | 落点相对 `base` 的偏移；`None` = 角色脚前 0.2 格 |

物理是**解析抛物线逐帧采样**（`z = vz·t − ½g·t²`），所以帧率变了轨迹也不会变慢变快，
只有采样点变密/稀。落地后 1 帧缩没，涟漪环同步淡出。

## 9. fog_gate —— 雾门 / 传送门（T41）

一张半透明自发光薄板 + 门框 + 两圈反向旋转的符文环；从地面“长”出来。

| 键 | 默认 | 单位 | 说明 / 调参建议 |
| --- | --- | --- | --- |
| `w` / `h` | 2.6 / 3.2 | 格 | 门宽 / 门高 |
| `thickness` | 0.03 | 格 | 门板厚度 |
| `dist` | 2.0 | 格 | 门离角色的前向距离 |
| `side` | 1.35 | 格 | 门中心相对角色中轴的右向偏移（摆放位置，不挡人） |
| `color` | `violet` | — | 雾面颜色 |
| `alpha` | 0.13 | — | 雾面不透明度；0.10~0.20，**高了就成实心板** |
| `strength` | 0.7 | — | 雾面自发光；1.5 以上变“亮板子” |
| `rune_strength` | 7.0 | — | 符文环自发光（这里就该亮） |
| `frame_strength` | 6.0 | — | 门框自发光 |
| `runes` | 8 | 个 | 内环符文块数量 |
| `spin` | 1.0 | 倍 | 外环转一圈所需的整段时长倍率（1 = 整段转一圈，2 = 半圈） |
| `grow` | 0.25 | ×total | 从地面长出来的时刻 |
| `light` | 45.0 | W | 门内点光源功率 |

结构要点：门板原点在几何中心，所以“长出来”时 **z 缩放与 location 联动**
（`scale.z 0.001→1` 同时把中心从地面抬到 `h/2`）；门框四根细条挂在门板上一起长；
内环符文块 parent 到内环 torus 上，跟着环一起转；两圈环反向转（`spin` 取负就是同向）。

## 10. 接入 pipeline（建议）

不改动现有文件的前提下，在配方执行阶段插入一段即可：

```python
from fx_kit import FX_REGISTRY

# ctx 从你已有的场景上下文拼出来（pipeline 里通常已经有 base / FV / UP / total / fps）
ctx = {'arm': arm_ob, 'total': total, 'fps': fps, 'base': base, 'FV': fv, 'UP': up}

for name, spec in (recipe.get('fx') or {}).items():
    fn = FX_REGISTRY.get(name)
    if fn is None:
        continue
    fn(scene, ctx, spec)
```

* 建议调用时机：**角色动画打好之后**（`glow_eyes` 要读骨骼位姿、`spawn_in` 可能要接管物品的 scale）。
* 建议在渲染前 `scene.frame_start/frame_end` 已确定，因为所有 `life` / `pop` / `collapse`
  都按 `total` 换算。
* 渲染完需要重跑时：`cleanup_fx()` 先清，再重新生成（不会留下重复件）。
* 想统一隐藏：`cleanup_fx(hide=True)`。

## 12. 已知限制

1. **泛光依赖渲染端合成器**。模块不自带 Glare；自测里接的 Fog Glow 只影响自测图，
   正式工程的观感由 `anim_kit.setup_render()` 决定。若眼睛/符文不够“发光”，
   优先检查合成器是否开了 Glare（阈值 1.0、强度 1.0、尺寸 0.6 左右）。
2. **只用 EEVEE 验证**。CYCLES 下自发光与 alpha 的表现略有差别（尤其 `alpha` 混合），
   需要时把 `alpha` 视为近似值。
3. **fog_gate 是单面朝向**：门板法线沿角色 `FV`，从正后方看会看到背面（同样半透明）。
   需要双面不同贴图时得改成两张板。
4. **spawn_in 只接管 scale**：如果目标物体自身有 scale 动画，会被覆盖；
   想共存就先给目标挂一个空物体当父级，再把包裹物当 `object`。
5. **`embers` 一颗一材质**：`n=200` 时会有 200 个材质，场景变重；
   需要极多火星时建议合并成几何节点/实例化（当前实现优先“可读、可调”）。
6. 所有坐标都是**世界坐标**；角色若被 parent 到别的物体上有位移，请把 `base` 传成
   角色的世界位置（`arm.matrix_world.translation`）。
