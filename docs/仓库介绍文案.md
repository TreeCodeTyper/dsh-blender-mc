```text
Minecraft save → Blender cover / clip. Auto-picks the camera azimuth (terrain + sun),
builds the scene with MCprep materials, BPS rig, three-point lighting and an AgX + compositor
```

`package.json` 的 `description` 就是 npm 页面的副标题：

```text
Minecraft 存档 → Blender 封面 / 动画：自动挑机位（地形 + 太阳方向）、MCprep 材质 + BPS 骨架 +
三点布光 + AgX 合成器后期；渲完用 OpenCV 审 8 项、不合格自动重渲。同一套场景可出 10 秒动画与分镜片。
```

## 5. 三处文案的「一致性红线」

无论改哪一处，这几条不能变，否则会被当成夸大：

1. 前置条件：Blender 4.2 LTS+、Python 3.10+、opencv-python、numpy、首次 `setup`；
2. 审图是「渲完自检 + 五类可自动修（yaw / 下沉 / 天空强度 / 灯倍率 / 相机距离）」，不是「全自动完美」；
3. 素材自带与否：插件**不附带** MCprep / BPS 骨架 / 物品库 / 贴图，都要 `mc_setup` 从本机装；
4. 版本号只在 package.json / CHANGELOG / 标签上出现，文案里不写具体版本号（除对比图外）。
