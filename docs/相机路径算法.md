# 相机路径算法（0.6.0）

`py/camera_path.py` 把“相机怎么走”从预设关键帧改成可计算路径：

1. **A\***：8 邻域，代价 = 步长 × (1 + 2×坡度)；只走有效地表。
2. **Theta\***：`theta_smooth` 从父节点向当前节点做视线检查，能直连就跳过中间栅格，
   去掉 A* 的锯齿。
3. **Catmull-Rom**：对稀疏路径按 `samples_per_seg` 重采样，得到平滑轨迹。

## 用法

```bash
python py/camera_path.py <save> --area=-100,100,-100,100 \
  --start=-68,65 --goal=43,83 --out=path.json
```

输出：

```json
{"start":[-68,65],"goal":[43,83],"points":[[x,z,y], ...]}
```

`y` 默认是地表 + 2.5，可传 `height_offset`。

## 边界

- 路径只保证“沿地表可走、坡度代价低”，不保证镜头不穿树；穿树检查仍需
  把 `TopMap.any` 纳入代价，或渲染后人工/自动复核。
- `mc_film` 目前仍用预设相机；要接入这条路径，需要在 `film.py` 里把
  `DSH_YJ_CAM_*` 换成逐帧路径点。
