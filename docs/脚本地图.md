## 四、改东西之前先看这张判断表

- **画面不对 / 背景脏 / 角色姿势怪** → `py/blender/build_cover.py`
- **动画动作不好看 / 太少 / 没有运镜** → `presets/*.json`（先试纯配置），不够再动 `anim_kit.py`
- **太慢** → `py/pipeline.py`（`step_render` / `gpu_args`）+ `build_cover.py` 的采样数
- **审图总说「天空死板 / 没轮廓光」** → `vision_check.py` 的判据 + `pipeline.auto_adjust`
- **多镜头 / 换场景 / 转场** → `py/film.py`（每镜 `blend`/`hour`/`fog` + `transition`）
- **想查上次跑了什么参数 / 复现一版** → `py/runs.py` + `python py/cli.py runs list|show|replay`
- **找不到存档 / 机位选得差** → `py/scan.py`、`py/search.py`
- **工具参数、返回结构** → `lib/index.js` + `py/cli.py`

## 五、新增一支动画（不写 Python 的标准流程）

1. 复制一份 `presets/walk.json` 当模板，改 `name` / `duration` / `motion` / `poses` / `camera`；
2. `python py/cli.py anim <封面.blend> --preset <新名字> --out <目录> --preview 1,30,60` 先看几帧；
3. 姿势对了去掉 `--preview` 渲全片；`--frames` 不传就用配方自己的 `duration`；
4. 想让它出现在提示词里，去 `py/prompt_film.py` 的预设表加一行；
5. 想让工具描述里能选，去 `lib/index.js` 的 `mc_anim` 描述里加名字。

**什么时候必须写 Python**：只有 `MOTIONS`（运动形状）/ `WEAPONS`（载具）/ `FX`（视觉元素）
三张表装不下你的新东西时。这三张表就是复用边界。
